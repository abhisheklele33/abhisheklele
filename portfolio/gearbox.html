TeleGlove — Bidirectional Glove for Real-Time Hand Motion Tracking and Haptic Feedback

Overview

TeleGlove is a bidirectional wearable haptic glove that enables real-time hand motion tracking and force-proportional haptic feedback. The system captures the full kinematic state of the hand — finger flexion via flex sensors, fingertip forces via FSRs, and global wrist orientation via an IMU — and maps it into a 3D virtual environment in Unity. Vibrotactile motors at the outer fingertips close the loop by providing haptic feedback proportional to simulated interaction forces.

Applications span teleoperation, surgical training, rehabilitation, virtual reality, and human-robot interaction — anywhere that requires intuitive, low-latency, closed-loop hand interaction in a virtual or remote environment.

System latency: under 100 ms virtual environment mapping · under 150 ms end-to-end haptic feedback from movement onset.

Sensor Integration & Design

Flex sensors are mounted along each finger to capture joint bending angles. Their resistance varies proportionally with curvature, allowing continuous, analog finger pose tracking across the full range of motion.

Force-sensitive resistors (FSRs) at each fingertip measure contact force magnitude during grasping or object interactions. These values are processed and transmitted to both the virtual environment (for physics simulation) and the haptic feedback system (for motor drive signals).

IMU (dorsal wrist) captures 6-DOF orientation and linear acceleration of the hand, enabling global pose tracking and gesture recognition. Sensor data are fused to produce a complete hand state vector.

Virtual Environment & Haptics

The Unity 3D virtual environment receives the fused hand state in real time and animates a corresponding virtual hand. Interactions such as grasping, squeezing, and throwing virtual objects trigger physics-based force computations. These computed forces are mapped back to vibrotactile motor intensities — creating a closed-loop system where the operator feels the virtual interaction through the glove.

The bidirectional nature of the system — sensing outbound and actuating inbound — distinguishes TeleGlove from pure tracking gloves and opens the door to genuine haptic teleoperation applications where remote force feedback is safety-critical.
